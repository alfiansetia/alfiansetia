### 🤖 How I Use AI

AI isn't a badge on my profile — it's the way I work now. Four things it actually looks like in my day-to-day:

| Area | What it looks like |
| --- | --- |
| **AI coding agents, daily** | Spec-driven development with [OpenCode](https://opencode.ai) / Claude Code style agents — scoping, refactors, code review, test generation. My repos carry `AGENTS.md` and `.ai/rules` so agents follow project conventions instead of guessing. |
| **LLM inside products** | Wiring OpenAI / Gemini / Claude APIs into apps: assistants, summarizers, structured output, chat and webhook flows. See [MindStep AI](https://github.com/alfiansetia/mindstep-ai). |
| **Local-first AI** | Running models locally for privacy and offline use — no account, no telemetry. The approach behind [DeskPet](https://github.com/alfiansetia/DeskPet) and MindStep AI's local LLM backend. |
| **Agent automation** | Browser and API automation that does real work: Playwright stealth scraping, WhatsApp API bots, webhook pipelines — e.g. [tiki-scrap](https://github.com/alfiansetia/tiki-scrap). |

> I use AI to go faster on the boring parts and to think harder on the important ones. Every generated line still has to pass review, tests, and a real network before it ships.
